# Đặc tả database HuyAcademy

## Quy ước

Schema mục tiêu cho PostgreSQL, chưa được triển khai trong code. Xem [quy tắc nghiệp vụ](API_references.md). Tên bảng/cột snake_case; entity Java camelCase. PK `bigint GENERATED BY DEFAULT AS IDENTITY`; FK cùng kiểu bigint. Thời điểm dùng `timestamptz`, ánh xạ Instant. Enum lưu varchar kèm CHECK, ánh xạ EnumType.STRING. Các cột không ghi NULL đều NOT NULL.

Migration Flyway tạo schema; Hibernate chỉ validate. created_at mặc định CURRENT_TIMESTAMP; updated_at được cập nhật bằng JPA auditing cho mọi lần ghi qua ứng dụng (không dùng cú pháp MySQL ON UPDATE). Dữ liệu ghi ngoài ứng dụng phải tự cập nhật updated_at.

## 1. users

| Cột | Kiểu / ràng buộc |
|---|---|
| user_id | PK |
| username | varchar(50), UNIQUE, chuẩn hóa chữ thường |
| password_hash | varchar(255), không trả ra API |
| email | varchar(100), UNIQUE, chuẩn hóa chữ thường |
| full_name | varchar(100), không rỗng |
| role | varchar(16), CHECK ADMIN/TEACHER/STUDENT, default STUDENT |
| is_active | boolean default true |
| token_version | bigint default 0, CHECK >= 0 |
| created_at, updated_at | timestamptz |

Không xóa user; vô hiệu hóa bằng is_active. Giới hạn đổi role và bảo vệ ADMIN cuối cùng thực hiện tại service trong transaction có kiểm soát đồng thời.

## 2. courses

| Cột | Kiểu / ràng buộc |
|---|---|
| course_id | PK |
| title | varchar(255), không rỗng; không bắt buộc duy nhất |
| description | text NULL |
| teacher_id | FK users(user_id) |
| price | numeric(10,2) default 0, CHECK >= 0 |
| duration_hours | integer NULL, CHECK > 0 khi có giá trị |
| status | varchar(16) default DRAFT, CHECK DRAFT/PUBLISHED/ARCHIVED |
| created_at, updated_at | timestamptz |

Service kiểm tra teacher có role TEACHER và đang hoạt động lúc giao/đổi giảng viên hoặc xuất bản.

## 3. lessons

| Cột | Kiểu / ràng buộc |
|---|---|
| lesson_id | PK |
| course_id | FK courses(course_id) |
| title | varchar(255), không rỗng |
| content_url | varchar(500) NULL, URL HTTP/HTTPS |
| text_content | text NULL |
| order_index | integer, CHECK >= 1 |
| is_published | boolean default false |
| created_at, updated_at | timestamptz |

Thứ tự đọc `order_index ASC, lesson_id ASC`. Cho phép trùng order_index để cập nhật thứ tự đơn giản và có kết quả ổn định. Service kiểm tra bài xuất bản có nội dung và giới hạn thay đổi tập bài khi đã có ghi danh.

## 4. enrollments

| Cột | Kiểu / ràng buộc |
|---|---|
| enrollment_id | PK |
| student_id | FK users(user_id) |
| course_id | FK courses(course_id) |
| enrollment_date | timestamptz default CURRENT_TIMESTAMP |
| status | varchar(16) default ENROLLED, CHECK ENROLLED/COMPLETED/DROPPED |
| completion_date | timestamptz NULL |
| progress_percentage | numeric(5,2) default 0, CHECK BETWEEN 0 AND 100 |

UNIQUE(student_id, course_id). CHECK: COMPLETED phải có completion_date và progress_percentage = 100; trạng thái khác phải có completion_date NULL. Service xác định hoàn thành theo số bài, không chỉ theo phần trăm đã làm tròn. DROPPED dành cho dữ liệu nghiệp vụ tương lai, chưa có endpoint chuyển sang trạng thái này.

## 5. lesson_progress

| Cột | Kiểu / ràng buộc |
|---|---|
| progress_id | PK |
| enrollment_id | FK enrollments(enrollment_id) |
| lesson_id | FK lessons(lesson_id) |
| is_completed | boolean default false |
| completed_at | timestamptz NULL |
| last_accessed_at | timestamptz default CURRENT_TIMESTAMP |

UNIQUE(enrollment_id, lesson_id). CHECK is_completed tương ứng completed_at có giá trị; chưa hoàn thành thì completed_at NULL. Service kiểm tra lesson.course_id = enrollment.course_id. last_accessed_at cập nhật khi học viên đọc nội dung đầy đủ hoặc hoàn thành bài; không cập nhật khi chỉ xem preview/danh sách.

## 6. notifications

| Cột | Kiểu / ràng buộc |
|---|---|
| notification_id | PK |
| user_id | FK users(user_id) |
| message | text, không rỗng |
| type | varchar(50) NULL |
| target_url | varchar(500) NULL, chỉ đường dẫn nội bộ bắt đầu bằng / |
| is_read | boolean default false |
| created_at | timestamptz default CURRENT_TIMESTAMP |

## 7. reviews

| Cột | Kiểu / ràng buộc |
|---|---|
| review_id | PK |
| course_id | FK courses(course_id) |
| student_id | FK users(user_id) |
| rating | integer CHECK BETWEEN 1 AND 5 |
| comment | text NULL, API giới hạn 5000 ký tự |
| created_at, updated_at | timestamptz |

UNIQUE(course_id, student_id). Service kiểm tra enrollment COMPLETED trước khi tạo.

## 8. revoked_tokens — bổ sung cho logout

| Cột | Kiểu / ràng buộc |
|---|---|
| jti | varchar(128) PRIMARY KEY |
| expires_at | timestamptz |

Lưu token bị logout đến thời hạn hết hiệu lực; tác vụ định kỳ dọn bản ghi hết hạn. Không lưu JWT nguyên văn. token_version trong users vô hiệu hóa toàn bộ token của một tài khoản khi cần.

## Index và tính toàn vẹn

- Unique constraints tự tạo index tương ứng; không tạo index trùng lặp.
- Bổ sung courses(teacher_id), courses(status, created_at, course_id), lessons(course_id, order_index, lesson_id).
- Bổ sung enrollments(course_id), lesson_progress(lesson_id), notifications(user_id, is_read, created_at), reviews(student_id), revoked_tokens(expires_at).
- Mọi FK mặc định ON DELETE RESTRICT. Xóa course DRAFT hợp lệ: xóa lessons rồi course trong cùng transaction; FK bảo vệ nếu xuất hiện enrollment đồng thời.
- Tìm kiếm ban đầu dùng truy vấn tham số hóa ILIKE; cân nhắc index chuyên biệt sau khi đo dữ liệu thực.
- Kiểm tra trước tại service để báo lỗi rõ, nhưng unique/check/FK ở database vẫn là lớp bảo vệ cuối. Chỉ ánh xạ lỗi constraint đã nhận diện thành 409/400; không biến mọi lỗi persistence thành conflict.
